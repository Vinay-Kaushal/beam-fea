# beam-fea

[![CI](https://github.com/Vinay-Kaushal/beam-fea/actions/workflows/ci.yml/badge.svg)](https://github.com/Vinay-Kaushal/beam-fea/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

A from-scratch 1D Euler-Bernoulli beam finite element solver in Python. It is verified
against closed-form beam theory and modal convergence, and validated against ANSYS
Mechanical, which you run by hand using [`ansys/ANSYS_GUIDE.md`](ansys/ANSYS_GUIDE.md).

Reference problem: steel cantilever, 500 × 20 × 10 mm (bending about the 10 mm depth),
100 N downward tip load.

## Quick start
```bash
python -m pip install -r requirements.txt
python -m pytest -q
python scripts/run_all.py      # writes results/summary.md
```
Or run `make install | test | run | clean`.

Key behaviours:
- The tip deflection is exact for any mesh, even one element (Hermite cubics).
- FE frequencies converge from above at about h⁴.
- The fixed-support peak stress in 3D is a singularity; compare mid-span stress instead.
